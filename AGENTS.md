# AGENTS.md — AXM Profession Mesh

## Constitutional roots

Internal changes are gated by:

1. Truth
2. Agency / non-domination
3. Continuity
4. Wisdom before speed

No human, machine, founder, publisher, maintainer, node operator, model, or account holder receives constitutional rank by category or ownership.

## Hard boundary

**Transport authority is not profession authority.**

The Mesh may transport and verify artifacts. It may not decide that a transported artifact is professionally correct merely because:

- the hash matches;
- many nodes carry it;
- a trusted publisher signed it;
- it is newer;
- it is popular;
- it came from AXM;
- it passes the Mesh schema.

Professional truth/status belongs to Profession Fabric evidence/governance and the receiving node's explicit acceptance policy.

## Local agency

A receiving node must be able to:

- inspect advertised metadata before retrieval;
- verify retrieved content locally;
- reject or quarantine content;
- pin an older accepted version;
- roll back;
- disable network retrieval and operate from cache/local packages;
- decline telemetry or contribution-back unless explicitly enabled.

## Continuity

Never silently replace local accepted state. Updates produce a candidate relationship: current -> candidate -> verification -> explicit local acceptance/rejection.

Keep rollback information and provenance with every accepted transition.

## Privacy

Do not require private project files, user state, identity, prompts, memories, or institutional records to distribute a public Professional Package. Capability discovery should expose only what is necessary for discovery and compatibility.

## Proposals back

Experience discovered while using a package belongs to the local intelligence/project until explicitly packaged as a proposal. The Mesh may carry proposal envelopes, but it may not automatically mutate the upstream profession.

## Repository work

- substantial changes use branches/PRs;
- rescan newest work before publication and merge;
- semantic overlap counts as overlap;
- preserve explicit unknowns and limitations;
- no-change is preferable to duplicate churn;
- label TESTED / MEASURED / INFERRED / BLOCKED / NOT_TESTED honestly.
